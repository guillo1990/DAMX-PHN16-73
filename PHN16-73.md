# Acer Predator PHN16-73

This repository contains a private adaptation of DAMX and Linuwu Sense for the Acer Predator PHN16-73 on CachyOS.

## Included changes

- The `driver/` subtree contains the patched Linuwu Sense source used by DKMS.
- The driver identifies `Predator PHN16-73` with the Predator v4 quirk and does not enable four-zone keyboard RGB.
- DAMX uses the driver-specific `damx_thermal_profile` interface when it is available.
- KDE Power Profiles and DAMX thermal profiles remain synchronized.
- DAMX shows Quiet both on battery and AC, and refreshes profile state while its window is open without writing the externally selected profile back.

## Profile mapping

| KDE profile | DAMX on battery | DAMX on AC |
| --- | --- | --- |
| Power Save | Quiet | Quiet |
| Balanced | Balanced | Balanced |
| Performance | Balanced | Performance |

DAMX Turbo maps to KDE Performance and is only available on AC.

## Installation

The installer is intentionally specific to this machine and performs DKMS builds for every installed kernel with headers. It creates a rollback backup under `/var/backups/damx-profile-sync`.

```bash
sudo ./install-profile-sync.sh
sudo ./install-gui-quiet-battery.sh
```

Reboot after `install-profile-sync.sh`. Close and relaunch DAMX after installing the GUI.

## Validation and rollback

Run validation on AC and battery:

```bash
./validate-profile-sync.sh
```

To restore the previous installation:

```bash
sudo ./rollback-profile-sync.sh
sudo ./rollback-gui-quiet-battery.sh
```
